🧠 Quick API Reference - Brain Tumor Endpoints
Standard Endpoints:
  • GET / - Documantation
  • GET /api/health - Health Check
  • GET /api/brain_tumor/classes - Tumor Classes
  • GET /api/brain_tumor/model/info - Model Info
  • GET /api/brain_tumor/analytics - Analytics
  • GET /api/brain_tumor/history - History
POST Endpoints:
  • POST /api/brain_tumor/predict - Single MRI
  • POST /api/brain_tumor/predict/batch - Multiple MRIs
  • POST /api/brain_tumor/debug/prediction - Debug
Research Endpoints:
  • GET /api/brain_tumor/results/charts - Charts
  • GET /api/brain_tumor/results/statistics - Stats
